# Mouse Tracker - Rata Interactiva

Un proyecto interactivo desarrollado con HTML, CSS y JavaScript. 

## ¿Cómo funciona?
Al mantener presionado el click del mouse en cualquier parte de la pantalla y arrastrarlo, una animación (`gif`) seguirá el movimiento del cursor por todo el fondo de forma fluida.

## Tecnologías utilizadas
* **HTML**: Estructura básica del documento.
* **CSS**: Fondo de pantalla completo, manejo de transiciones suaves para el delay del movimiento y ocultamiento del cursor nativo.
* **JavaScript**: Manipulación del DOM y escucha de eventos del mouse (`mousedown`, `mouseup`, `mousemove`) para capturar las coordenadas dinámicas (`clientX` / `clientY`).
